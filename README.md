# Megan Ormonde - Portfolio Website

A personal portfolio website showcasing software engineering skills and projects.

## 🚀 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Dark/Light Theme Toggle**: Switch between dark and light color schemes
- **Interactive Projects**: Playable memory game and number guessing game
- **Smooth Scrolling**: Enhanced navigation experience
- **Accessibility**: WCAG compliant with proper ARIA labels and semantic HTML

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript**: Vanilla JS with jQuery for enhanced interactions
- **Bootstrap 5**: Responsive framework for layout and components
- **Google Fonts**: Noto Sans KR for typography

## 🎮 Interactive Projects

### Memory Matching Game
- Test your memory skills by matching pairs of cards
- Tracks flips and matches
- Responsive design with smooth animations

### Higher/Lower Game
- Guess the magic number between 1 and 100
- Limited attempts with feedback
- Win/lose states with visual feedback
